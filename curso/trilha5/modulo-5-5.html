📋 awesome-claude-code (Curated List on GitHub)

The repositoryawesome-claude-codeon GitHub and the mandatory starting point for anyone looking for ready-made skills. And a list curated by the community that brings together the best skills, tools and resources for Claude Code, organized by categories and constantly updated.

Main Concept

🎯Main Concept

O awesome-claude-codefollows GitHub's "awesome lists" pattern, a time-honored tradition for curating the best features of any technology. In the context of Claude Code, he catalogs:

  • • Individual skills:.md files ready to copy and use, organized by purpose (code review, testing, documentation, refactoring)
  • • Skill collections:Thematic packages created by power users that solve complete development workflows
  • • Complementary tools:CLIs, extensions and integrators that expand the capabilities of skills in everyday life
  • • Community update:Anyone can contribute via PR, and maintainers check quality before accepting
Practical Tip

💡Practical Tip

Star the awesome-claude-code repository and enable release notifications. The list is updated frequently and you will be notified when new high-quality skills are added.

Extra tip:start with the skills with the most stars and forks- they have been validated by more people and tend to have better documentation and fewer bugs.

📂 awesome-agent-skills and awesome-claude-skills

In addition to the generalist awesome-claude-code, there are repositoriesspecialized exclusively in skills. awesome-agent-skills focuses on agnostic skills (works with multiple AI agents) and awesome-claude-skills is dedicated to skills optimized specifically for Claude.

Main Concept

🎯Main Concept

These repositories complement awesome-claude-code with a narrower and deeper focus:

  • • awesome-agent-skills:Skills that work with Claude Code, Cursor, Windsurf and other agents. Useful if you work with multiple tools or want portability
  • • awesome-claude-skills:Skills optimized exclusively for the Claude ecosystem. Take advantage of specific features such as slash commands, subagents and hooks
  • • Detailed categorization:Both organize by domain (frontend, backend, DevOps, data science, documentation) making it easy to find exactly what you need
  • • Active contribution:The Claude Code community in 2026 is extremely active, with hundreds of new skills published monthly
Practical Tip

💡Practical Tip

Prefer skillsawesome-claude-skillswhen possible, as they are optimized for Claude Code and take advantage of the tool's full potential. Use skills from awesome-agent-skills when you need compatibility with other agents or when you cannot find an equivalent in the Claude-specific repository.

⚡ Frameworks: Superpowers, everything-claude-code

Frameworks go beyond individual skills. They arecomplete packages that install dozens of skills at once, automatically configuring the environment for maximum productivity. The two most popular in 2026 are Superpowers and everything-claude-code.

Main Concept

🎯Main Concept

Skills frameworks are like "starter kits" that transform your Claude Code into a productivity machine:

  • • Superpowers:Framework that adds advanced productivity skills, including automated workflows, project templates, documentation generation and AI-assisted CI/CD pipelines
  • • everything-claude-code:Comprehensive collection covering everything from basic skills to advanced workflows. Ideal for those who want a complete setup without setting up skill by skill
  • • Simple installation:Generally just clone the repository and copy the commands folder to your project or global directory
  • • Customization:Well-designed frameworks allow you to enable/disable individual skills and customize behaviors without modifying the source code
Practical Tip

💡Practical Tip

Don't install everything at once. Start with a framework andOnly activate the skills you will actually use. Unnecessary skills can pollute autocomplete and make it difficult to find the commands that matter. The rule is: less and more, as long as it covers your critical workflows.

🏪 Marketplaces: SkillsMP, SkillHub, awesomeclaude.ai

In 2026, the ecosystem has matured to the point wherededicated marketplaces for Claude Code skills. These sites offer advanced search, user reviews, one-click installation, and even high-quality premium skills.

Main Concept

🎯Main Concept

The main marketplaces and their characteristics:

  • • SkillsMP:Community marketplace with rating and reviews system. Free and premium skills. Filters by language, framework and use case. Installation via integrated CLI
  • • SkillHub:Focused on skills for teams and companies. Offers skills with quality SLAs, support and guaranteed updates. Ideal for corporate use
  • • awesomeclaude.ai:Web directory with visual interface to explore, compare and install skills. Includes previews, usage examples and popularity metrics
  • • Advantage over GitHub:Marketplaces offer semantic search, more granular categories, compatibility checking and automated installation
Practical Tip

💡Practical Tip

Use marketplaces todiscoverand GitHub foraudit. When you find an interesting skill on the marketplace, always check the source repository on GitHub before installing. Check open issues, frequency of commits and whether the author is active in the community.

⭐ Assessing Skills Quality (Audit Criteria)

Not every published skill is good. To knowassess quality before adoptingIt is essential to avoid problems, inconsistent outputs and wasted tokens with poorly written skills.

Main Concept

🎯Main Concept

Audit checklist to evaluate a skill before use:

Criteria Table
Criterion What to check Red Flag
Structure Purpose, Steps, Quality Checks defined No light sections
Specificity Detailed and unambiguous instructions Vague instructions
Verification Measurable success criteria No quality checks
Community Stars, forks, issues answered Zero engagement
Maintenance Recent commits, changelog Abandoned for months
Practical Tip

💡Practical Tip

Create onetest environmentto evaluate skills before using them in real projects. Open a temporary project, install the skill and run it with known inputs. Compare the output with what you would produce manually. If the skill generates consistent results in 3 consecutive tests, it passes the minimum quality criteria.

🔒 Security: Auditing Before Installing

Skills are markdown files that instruct powerful AI. A malicious skill caninstruct Claude to execute dangerous commands, exfiltrate data, or modify code in subtle ways. Security audit is mandatory before installing any third-party skill.

Main Concept

🎯Main Concept

Critical security points when evaluating third-party skills:

  • • Read the entire markdown:Never install a skill without reading every line of the file. Look for instructions that ask Claude to execute shell commands, access the network, or modify files outside of scope
  • • Beware of prompt injection:Skills may contain instructions hidden in HTML comments or formatting that instruct Claude to bypass security restrictions
  • • Check the author:Check out the author's history on GitHub. New profiles without history are more risky. Prefer skills from well-known authors in the community
  • • Principle of least privilege:Skills should not ask for more permissions than necessary for the task. A "code review" skill does not need to access the file system or make HTTP requests
Practical Tip

💡Practical Tip

Before installing any third-party skill, run this mental checklist:

1)Have I read the entire markdown?2)Do I know the author or does the repo have a good reputation?3)Does the skill only ask for the necessary permissions?4)Did I test in an isolated environment? If any answer is "no",do not install.
