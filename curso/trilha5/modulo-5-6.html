📦 What are Plugins (Skills Bundles + MCPs + Tools)

Plugins are thehighest level of extensibilityby Claude Code. While a skill is an individual workflow, an MCP is a tool integration, a plugin is acomplete package that combines everything: skills, MCP servers, custom tools and pre-defined configurations.

Main Concept

🎯Main Concept

Think of plugins as"apps" for your Claude Code. Just like you install apps on your phone to add functionality, plugins add complete capabilities:

  • • Skills included:The plugin brings pre-written skills optimized for the specific domain (e.g. database plugin brings query, migration, seed skills)
  • • Integrated MCPs:Necessary MCP servers are already configured and ready to use, without manual setup
  • • Custom tools:Specialized tools that expand what Claude can do in the context of the plugin
  • • Zero configuration:Installing a plugin is enough. It configures everything automatically and it works in the next session
Practical Tip

💡Practical Tip

The decision rule is simple:if you need full functionality on a domain(database, design, deploy, monitoring), look for a plugin. If you just need a specific workflow, use a skill. Plugins save setup time but add more weight to the environment.

🌐 The Ecosystem of 9000+ Plugins

In 2026, Claude Code's plugin ecosystem surpassed the9000 plugins available. This explosion of growth reflects the maturity of the platform and the strength of the community of actively contributing developers.

Main Concept

🎯Main Concept

The ecosystem is organized into layers of maturity and reliability:

  • • Official plugins (Anthropic):Created and maintained by Anthropic. Guaranteed quality, constant updates, official support. Examples: integrations with GitHub, Jira, Slack
  • • Verified plugins:Created by the community but reviewed and approved. They are audited for quality and safety before receiving the verification seal
  • • Community plugins:Created by any developer. They vary a lot in quality. Require manual auditing before use in production
  • • Exponential growth:From ~200 plugins in early 2025 to 9000+ in 2026. The growth rate continues to accelerate with the popularization of Claude Code
Practical Tip

💡Practical Tip

With 9000+ options,Don't try to explore everything. Start with the official, verified plugins in your work category. Use the marketplace popularity and rating filters. A good starting point: install the 5 most popular plugins in your area (e.g. frontend, backend, data) and explore from there.

⬇️ Installing Plugins (Marketplace, CLI)

There are two main ways to install plugins on Claude Code: viamarketplace with visual interfaceor viaCLI directly in the terminal. Both are equally valid and the final result is identical.

Main Concept

🎯Main Concept

Installation methods and their flows:

# Via CLI - direct installation
$ claude plugin install supabase
# Via CLI - fetch before installing
$ claude plugin search "database"
# Via CLI - list installed plugins
$ claude plugin list
# Via CLI - remove plugin
$ claude plugin remove supabase
  • • Marketplace:Web interface with preview, documentation and install button. Ideal for exploring and comparing options before deciding
  • • CLI:Faster for those who already know what they want. One command and the plugin is installed and ready to use
  • • Auto-configuration:Well-made plugins detect your environment and configure themselves automatically. If you have a Supabase project, the plugin detects it and connects
Practical Tip

💡Practical Tip

After installing a plugin, always runclaude plugin listto confirm that it was installed correctly. Then open a new Claude Code session and type/to see the new slash commands available. If nothing appears, check for configuration errors.

🗄️ Supabase Plugin (Database Integration)

The Supabase plugin is one of thebest examples of well-implemented plugins. It integrates Claude Code directly with Supabase, allowing you to manage databases, authentication, storage and edge functions without leaving the terminal.

Main Concept

🎯Main Concept

What the Supabase plugin includes and how it works in practice:

  • • Integrated MCP Server:Connects directly to your Supabase project, allowing SQL queries, table creation and real-time data management
  • • Database skills:Skills ready for migrations, seeds, backups and complex queries. You describe what you need and Claude generates and executes it
  • • Automatic detection:If you have asupabase/at the root of the project, the plugin detects and configures the connection automatically
  • • Slash commands:Commands like/supabase-query, /supabase-migrate, /supabase-seedbecome available automatically
Practical Tip

💡Practical Tip

The Supabase plugin is a model for how plugins should be built. By studying its architecture, you learn the patterns that the best plugins follow:automatic environment detection, well-documented skills, MCP with limited scope and zero configuration. Use it as a reference when evaluating other plugins.

🛠️ Creating your own plugin (/skill-creator)

The Claude Code includes the command/skill-creatorwhich facilitates the creation of customized plugins. You describe what the plugin should do and Claude generates the complete structure, including skills, MCP configuration and plugin manifest.

Main Concept

🎯Main Concept

The structure of a plugin is made up of:

my-plugin/
manifest.json# Metadata and configuration
commands/# Plugin skills
skill-1.md
skill-2.md
mcp/#MCP Servers
server.js
tools/# Extra tools
helper.sh
README.md# Documentation
  • • manifest.json:Defines name, version, description, dependencies, included skills and MCPs configuration of the plugin
  • • /skill-creator:Built-in command that guides you in creating the complete structure. Enter the domain and it generates the skeleton
  • • Publication:Plugins can be published on the marketplace or shared via GitHub. The verification process takes 2 to 5 business days
Practical Tip

💡Practical Tip

Before creating a plugin from scratch, check if something similar already exists. With 9000+ plugins, there is a good chance that someone has already solved your problem. If you decide to create,start with /skill-creator and iterate from the generated skeleton. Don't try to build everything by hand - Claude does 80% of the heavy lifting for you.
