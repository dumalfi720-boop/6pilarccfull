🌐 What MCP Browser does

MCP Browser gives Claude the ability toopen a real Chrome browser, browse pages, take screenshots, click on elements and extract data. It uses the Chrome DevTools Protocol to control a headless or visible browser, turning Claude into an assistant that "sees" the web.

🎯Main Concept

MCP Browser and morepowerful and expensivein terms of tokens. It allows:

  • •Navigation:Open URLs, click on links, fill out forms
  • •Screenshots:Capture the entire screen or specific elements
  • •Interaction:Clicking buttons, typing text, scrolling
  • •Extraction:Read content of pages, tables, lists

💡Practical Tip

Only use MCP Browser when you really need itseesomething. To read content from APIs, use direct requests. The Browser is for when you need the visual experience: checking layout, comparing UI, or scraping sites that don't have an API.

TOPIC 2

⚙️ Installing MCP Browser

Installing Browser MCP follows the same pattern as other MCPs, with a single command.

🎯Main Concept

$ claude mcp add browser -- npx @anthropic-ai/mcp-browser

MCP Browser requires Chrome to be installed on the system. It uses the Chrome DevTools Protocol to control an instance of the browser. On headless systems (without a screen), it runs in headless mode automatically.

💡Practical Tip

After installing, test with something simple:"Abra google.com e tire um screenshot". If it works, you're ready for more complex scenarios.

📷 Screenshot + Visual Comparison

MCP Browser's most valuable use case is thevisual check loop: you implement something, Claude takes a screenshot and compares it with the expected design. This eliminates the back and forth between code and browser.

🎯Main Concept

The visual verification loop works like this:

  • •1. Implement:Claude writes the CSS/HTML/React code
  • •2. Screenshot:Claude takes a screenshot of the rendered page
  • •3. Compare:Claude analyzes whether it is in line with expectations
  • •4. Adjustment:If necessary, correct and repeat the cycle

💡Practical Tip

For UI, say:"Implement the header, then open localhost:3000 and take a screenshot. Compare with the design and adjust if necessary."Claude does everything himself - and visual perfection without you opening the browser.

🕷️ Web Scraping with Claude

In addition to visual verification, Browser MCP andexcellent for web scraping. Claude can browse websites, extract structured data, and save to useful formats like JSON or CSV.

🎯Main Concept

  • •Extract tables:Read tables from any website and convert to JSON/CSV
  • •Browse pagination:Scroll through multiple pages automatically
  • •Forms:Complete and submit search forms
  • •Dynamic websites:Wait for JavaScript to load before extracting

💡Practical Tip

Combine Browser + Sheets for complete scraping pipelines:"Open page X, extract the price table and save it in a Google Sheets spreadsheet". Two MCPs working together.

TOPIC 5
5

⚠️ HIGH Impact Token

Important notice: Browser MCP has thebiggest impact on tokens of all MCPs. Screenshots are base64 encoded images that consume thousands of tokens each. A session with many screenshots can quickly exhaust your context.

🎯Main Concept

  • •Full page screenshot:~2,000-5,000 tokens per capture
  • •Tools description:MCP Browser exposes many tools, each occupying context
  • •Short sessions:Plan UI sessions as focused sprints
  • •Compress and focus:Prefer screenshots of specific elements instead of entire pages

💡Practical Tip

Monitor with/costevery 2-3 screenshots. If the cost is rising quickly, finish the visual check and disconnect the Browser before continuing to code.

TOPIC 6
6

🚫 Operator Rule: Disconnect When Not Using UI

This is the most important rule of MCP Browser:unplug it when not doing visual work. It doesn't make sense to pay the Browser context cost while you are writing backend logic or configuring the database.

🎯Main Concept

The ideal flow with MCP Browser:

  • •Do you need UI? claude mcp add browser→ does the job →claude mcp remove browser
  • •It is not necessary?Don't even connect. Save tokens for what matters.

💡Practical Tip

Create an alias in the terminal:alias browser-on="claude mcp add browser -- npx @anthropic-ai/mcp-browser" e alias browser-off="claude mcp remove browser". On and off in 2 seconds.
