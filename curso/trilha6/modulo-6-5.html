📄 MCP Google Sheets (Read/Write Spreadsheets)

MCP Google Sheets allows Clauderead and write directly in Google Sheets. This connects your development workflow with the world of tabular data - reports, dashboards, CRMs and any spreadsheet you use on a daily basis.

🎯Main Concept

  • •Reading:Pull data from any spreadsheet for analysis or processing
  • •Writing:Export results, reports and processed data to spreadsheets
  • •Ranges:Work with specific ranges (A1:Z100) to save tokens
  • •Token impact:Low to moderate - depends on data volume

💡Practical Tip

Always specifyrangesinstead of entire spreadsheets. "Read A1:E50 from the Sales tab" is much more efficient than "read the entire Sales spreadsheet".

TOPIC 2
2

⚙️ Installing Google Sheets

Installing MCP Google Sheets requires configuring Google Cloud API credentials. The process is a little longer than other MCPs, but it only needs to be done once.

🎯Main Concept

$ claude mcp add google-sheets -- npx @anthropic-ai/mcp-google-sheets

After the command, follow the authentication prompts. You will need:

  • •1.Enable Google Sheets API in Google Cloud Console
  • •2.Create OAuth 2.0 credentials
  • •3.Authorize access on first run

💡Practical Tip

If setting up credentials seems complicated, use theService Accountinstead of OAuth. It is easier to configure for automation and does not require user interaction.

🚀 Use Cases (Export, Dashboards, CRM Sync)

Google Sheets MCP shines in scenarios that connect development with business operations.

🎯Main Concept

  • •Data export:"Scrape prices from site X and save in spreadsheet Y" (Browser + Sheets)
  • •Dashboard updates:"Update the Metrics tab with the latest bank data" (Postgres + Sheets)
  • •CRM sync:"Read the spreadsheet leads and create GitHub issues for each one" (Sheets + GitHub)
  • •Reports:"Generate a weekly commit report and save it in the tracking spreadsheet"

💡Practical Tip

The comboBrowser + Sheetsand perfect for lead scraping: Claude navigates websites, extracts data and saves it structured in the spreadsheet. Automate what used to be manual copying and pasting.

🔧 Other Useful MCPs (Notion, Slack, Linear, Gmail, Figma)

In addition to the core MCPs, there is a growing ecosystem of integrations. Here are the most useful ones for development teams.

🎯Main Concept

  • •Notion:Manage Notion docs, wikis, and databases right from Claude
  • •Slack:Send messages, read channels, and reply to threads without opening Slack
  • •Linear:Manage issues, sprints and projects for your team
  • •Gmail:Read and send emails programmatically
  • •Figma:Access designs, extract specs and components

💡Practical Tip

Don't install them all at the same time. Remember Token Tax. Installon demand- when a specific task requires that integration.

TOPIC 5
5

💡 When to Install Each One (Task-Based Decision)

The decision to install an MCP should betask-based, not "nice to have". Here is the decision framework.

Framework: Install Immediately vs When You Need It

CategoryMCPs
Install immediatelyFilesystem, GitHub
Install when you needBrowser, Database, Google Sheets
Install on demandNotion, Slack, Linear, Gmail, Figma

💡Practical Tip

Before installing an MCP, ask:"Am I going to wear this for the next 2 hours?". If not, do not install now. You can add any MCP in 5 seconds whenever you need.

TOPIC 6
6

🛠️ Managing MCPs (list, remove, re-add)

Managing MCPs is just as important as installing them. The three essential commands that you will use constantly.

🎯Main Concept

# View all active MCPs
$ claude mcp list
# Remove an MCP
$ claude mcp remove browser
# Re-add when needed
$ claude mcp add browser -- npx @anthropic-ai/mcp-browser

💡Practical Tip

Create a filemcps.shwith all the installation commands for your favorite MCPs. When you need to reinstall, just run the script. Fast and consistent.
