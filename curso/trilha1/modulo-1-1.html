🚀 What is Claude Code

Claude Code and theAnthropic's most advanced agentic CLI tool. Unlike traditional chatbots, it runs directly in your terminal, reads and edits files, executes commands, understands the complete structure of your codebase and takes concrete actions. It is not a question and answer interface. And an assistant who acts.

Main Concept

🎯Main Concept

Claude Code and acoding agentthat operates in the terminal. When you start a session, it maps the project directory, understands the folder structure, identifies languages ​​and frameworks, and is ready to perform complex development tasks.

  • • Runs in the terminal:It is not a web interface. You interact via the command line, which means direct access to the file system, git, npm, docker, and any CLI tools you already use
  • • Read and write files:Claude Code opens, reads, edits and creates files in your project. It doesn't just suggest code. It applies the changes directly, with visual diff for you to approve
  • • Execute commands:Run npm install, git commit, pytest, docker build and any other command necessary to complete the task. With your permission, of course
  • • Understands the codebase:Instead of you copying and pasting code into chat, Claude Code navigates the entire project, finds dependencies, identifies patterns, and makes consistent changes across multiple files

  • 4%of all public commits on GitHub are generated by Claude Code

Practical Tip

💡Practical Tip

The quickest way to understand the power of Claude Code is to use it. Navigate to any project in the terminal, typeclaudeand ask, "What does this project do?" In seconds, it will read the codebase and provide a structured analysis that would take 30 minutes manually.

Don't think of it as "AI that writes code". Think like asenior colleague who just sat next to you, has access to your entire project and can execute any command you would ask for.

🔀 Claude Chat vs Code vs Cowork

Anthropic offers three distinct interfaces for Claude, each optimized for a different type of work. Understanding the differences is fundamental to using theright tool at the right time. Many people try to do everything in Chat when they should be in Code, or use Code when Cowork would be more efficient.

Main Concept

🎯Main Concept

Each product has a clear domain. When you use the right tool, productivity multiplies. When you use the wrong one, you fight the interface.

  • • Claude Chat (claude.ai):Web interface for conversations, document analysis, brainstorming, text creation. You send messages and receive responses. It doesn't have access to your file system, it doesn't execute commands, it doesn't modify code. Ideal for thinking.
  • • Claude Code (CLI terminal):Agentic coding agent. Run in the terminal, read your entire codebase, edit files, execute shell commands, make commits, create PRs. Ideal for building.
  • • Claude Cowork (desktop agent):Desktop agent for knowledge work. Manage files, create presentations, organize documents, connect with services via connectors. Ideal for producing non-code deliveries.
Comparison Table

Detailed Comparison

Feature Chat Code Coworking
Interface Web (browser) CLI terminal Desktop app
File access Manual upload Read/write directly Via connectors
Execute commands No Yes (full shell) Limited
Integrated Git No Yes (/commit, /pr) No
Codebase awareness No Yes (complete) No
Best for Think, analyze Build, code Produce, organize
Practical Tip

💡Practical Tip

Simple decision rule: get involvedcode and terminal, use Claude Code. Get involvedtalk and analyze, use Claude Chat. Get involvednon-code files and general productivity, use Cowork.

When in doubt: if you need Claude to execute something (run a command, edit a file, make a commit), the answer is Claude Code. If you just need to think together, it's Chat.

Do vs Avoid

✓ What TO DO

  • ✓ Use Claude Code for any task involving your codebase
  • ✓ Use Chat to plan architecture before implementing in Code
  • ✓ Combine tools: plan in Chat, execute in Code

✗ What NOT to do

  • ✗ Copy/paste code into Chat when you could open Claude Code in the project
  • ✗ Try using Claude Code to write long emails or documents
  • ✗ Skip Cowork for non-code productivity tasks

📋 Prerequisites

Before installing Claude Code, you need tofew things, but they are all mandatory. The good news: if you're a developer, you probably already have almost everything. Let's check item by item.

Main Concept

🎯Main Concept

Claude Code runs as a global npm package. This means you need Node.js installed and an Anthropic account with a paid plan for authentication. The rest is optional but recommended.

  • • Anthropic account (required):Pro Plan ($20/month), Team or Enterprise. The free plan does not include access to Claude Code. Pro gives a generous monthly usage limit that covers most workflows
  • • Node.js 18+ (required):It is recommended to use version 20 LTS. You can check withnode --version. If you don't have it or it's out of date, use nvm to install
  • • Modern terminal (required):Any terminal works: Terminal.app (macOS), iTerm2, Warp, Windows Terminal, Alacritty, Kitty. Your OS's default terminal already works
  • • Operating system:macOS, Linux or Windows with WSL. On Windows without WSL, operation is limited. Strong recommendation: use WSL if you are on Windows

Practical Tip

💡Practical Tip

If you don't have Node.js or need to update, the cleanest way is to usenvm(Node Version Manager). Install nvm and then runnvm install 20followed bynvm use 20. This avoids permission issues and conflicts with previous versions.

On Windows,do not try to install Claude Code in native PowerShell. Use WSL. Operation on Windows without WSL has many known limitations and bugs. 5 minutes configuring WSL saves hours of frustration.

⚙️ Installation

Installing Claude Code is straightforward: a single npm command. But there are details ofauthentication and verificationthat you need to get right the first time. Let's go step by step.

Main Concept

🎯Main Concept

Claude Code is distributed as a global npm package. The installation puts the binaryclaudein your PATH, available in any directory in the terminal. After installing, you authenticate once and you are ready.

  • • Global Package:Single installation that is available throughout the system. No need to install per project
  • • Authentication via browser: O claude loginOpen your browser to authenticate with your Anthropic account. The token is saved locally
  • • Updates:Update withnpm update -g @anthropic-ai/claude-code. New versions come out frequently with significant improvements
Code Blocks

💻Installation Commands

1. Install Claude Code globally:

$ npm install -g @anthropic-ai/claude-code

2. Check if the installation worked:

$ claude --version
# It should display something like: claude-code 1.x.x

3. Authenticate with your Anthropic account:

$ claude login
# Open the browser for OAuth authentication

4. Start your first session:

$ cd ~/projects/my-project
$ claude
Alert - Common Errors

⚠️Common Errors and Solutions

EACCES: permission denied

Global npm permissions issue. Solution: Configure npm to use a local directory withnpm config set prefix ~/.npm-globaland add to PATH. Or use nvm (recommended).

Incompatible node version

Claude Code requires Node.js 18+. Check withnode --version. If less than 18, update via nvm:nvm install 20 && nvm use 20.

claude: command not found

The binary is not in the PATH. Rotatenpm list -g @anthropic-ai/claude-codeto confirm the installation. If installed, the global npm PATH is not configured. Usewhich claudeor add npm prefix to PATH.

Something weirder?

Rotate/doctorwithin a Claude Code session. It diagnoses and attempts to resolve configuration issues automatically.

Practical Tip

💡Practical Tip

If you useVS Code, Claude Code also has a native extension that integrates directly into the editor. But start with the terminal: understanding the pure CLI first gives you more control and understanding of how everything works underneath.

Keep Claude Code updated. Updates are frequent (almost weekly in 2026) and bring significant improvements. Rotatenpm update -g @anthropic-ai/claude-codeperiodically or create an alias:alias ccup='npm update -g @anthropic-ai/claude-code'.

🖥️ First Session

Your first session at Claude Code is the moment when everything makes sense. You navigate to a project, typeclaude, and the wizard reads your codebase automatically. Let's see exactlywhat happens and what to expect.

Main Concept

🎯Main Concept

When starting Claude Code in a directory, it automatically scans the project. If a file existsCLAUDE.mdAt the root, it carries these instructions as persistent context. Without CLAUDE.md, it still works, but without custom instructions.

  • • Automatic scan:Claude maps the directory structure, identifies languages, frameworks and project dependencies
  • • CLAUDE.md:If it exists, it functions as "briefing instructions". You can define style rules, preferred stack, naming standards and expected behaviors (we will see this in Track 2)
  • • Interactive interface:After the scan, you see a prompt area where you type instructions. Claude responds, uses tools (Read, Write, Bash, etc.) and shows indicators of which tools he is using
  • • Cost indicator:In the session footer, you see the tokens consumed and the accumulated cost. This number grows with each interaction

Practical Tip

💡Practical Tip

In the first session, focus onexplore, don't modify. Ask questions about the project, ask him to explain parts of the code, ask about dependencies. When you are comfortable with the interface, then start asking for changes.

Useful shortcuts right from the first session:Exhaustcancels the current generation,Shift+Tabactivates multi-line mode for long prompts, and/helpshows all available commands.

Do vs Avoid

✓ What TO DO

  • ✓ Start with exploratory questions before asking for changes
  • ✓ Observe which tools Claude uses to understand the flow
  • ✓ Start with a project that you know well to validate the answers

✗ What NOT to do

  • ✗ Requesting complex changes in the first session without understanding the interface
  • ✗ Approve all actions without reading the diffs shown
  • ✗ Start with an empty project (the scan won't have much to analyze)
