🧭 Session Navigation

When a Claude Code session gets long, with lots of answers and code blocks,knowing how to navigate quickly is essential. Instead of scrolling infinitely with the mouse scroll, use shortcuts to jump between answers, search for specific content and find information quickly.

Main Concept

🎯Main Concept

Claude Code runs inside your terminal, so navigation shortcuts depend on the terminal emulator you use. However, there are universal shortcuts that work on practically all modern terminals.

  • • Basic scroll:UseShift+PageUp e Shift+PageDownto scroll an entire page. In many terminals,Ctrl+Shift+Up/Downscroll line by line
  • • Terminal search: Ctrl+Shift+Fin most terminals it opens the text search. Search for function names, errors, or any text in the output
  • • Clear screen: Ctrl+Lclears the screen without closing the session. The history remains accessible via scroll
  • • Tmux/Screen:If you use tmux,Ctrl+b [enters copy/navigation mode, allowing scrolling with vim keys (j/k/Ctrl+f/Ctrl+b)
Shortcut Table

Terminal Navigation Shortcuts

Action iTerm2/macOS Windows Terminal Linux (GNOME)
Scroll up Cmd+Up / Fn+Up Ctrl+Shift+Up Shift+PageUp
Scroll down Cmd+Down / Fn+Down Ctrl+Shift+Down Shift+PageDown
Search text Cmd+F Ctrl+Shift+F Ctrl+Shift+F
Clear screen Cmd+K Ctrl+L Ctrl+L
Practical Tip

💡Practical Tip

If you use long sessions, consider using thetmuxto manage your Claude Code session. With tmux, you can split the screen, keep sessions in the background and browse the history with vim keys, which is much faster than standard scrolling.

Another option: use/clearinside Claude Code periodically to clean up the visual context. This does not affect the knowledge of the session, it just clears the screen.

✏️ Prompt Editing

Typing long prompts in the terminal can be cumbersome without the right shortcuts. Youline editing shortcutsfrom readline (used by bash, zsh and Claude Code) allow you to move the cursor, delete words and edit text with professional speed. Mastering these shortcuts eliminates the frustration of having to rewrite entire prompts because of a mistake halfway through.

Main Concept

🎯Main Concept

Claude Code uses a readline/line-editor-based input interface, which means that classic Emacs shortcuts work to navigate and edit the prompt text before sending. These are the same shortcuts you already use in bash/zsh.

  • • Ctrl+A / Ctrl+E:Move the cursor to the beginning / end of the line. Essential for editing long prompts without using arrow keys
  • • Ctrl+W:Delete the word before the cursor (backspace per word). Much faster than holding backspace
  • • Ctrl+U:Delete everything from the cursor to the beginning of the line. Quickly clear prompt for rewrite
  • • Ctrl+K:Delete everything from the cursor to the end of the line. Ctrl+U add-on
  • • Alt+B / Alt+F:Move the cursor one word back/forward. Quick navigation between prompt words
Shortcut Table

Essential Editing Shortcuts

Shortcut Action When to Use
Ctrl+A Start of line Add text to the beginning of the prompt
Ctrl+E End of the line Return to the end after editing the middle
Ctrl+W Delete previous word Correct the last word typed
Ctrl+U Delete to beginning Clear everything and rewrite
Ctrl+K Delete until the end Keep start and change end
Alt+B Previous word Navigate between words

Practical Tip

💡Practical Tip

The most useful combo in everyday life andCtrl+Uto clear the prompt when you change your mind mid-typing. Instead of holding backspace for 5 seconds, a single shortcut instantly clears everything.

On macOS with iTerm2,Alt+B/FIt may not work by default. Go to Preferences > Profiles > Keys and change "Left Option key" to "Esc+" to enable Alt shortcuts.

🛑 Execution Control

To knowinterrupt, cancel and control executionby Claude Code is as important as knowing how to ask for things. When Claude is generating a very long response, executing a wrong command or taking a path you don't want, you need to act quickly. These shortcuts are your safety net.

Main Concept

🎯Main Concept

Claude Code offers different levels of interruption, from canceling the current generation to exiting the session completely. Understanding the difference between them is crucial to maintaining control.

  • • Exhaust:Cancels the generation in progress. Claude stops responding, but the session remains active. Use when the answer is going in the wrong direction
  • • Ctrl+C (once):Interrupts the current operation. If Claude is executing a command or generating text, it stops. You can continue the conversation normally
  • • Ctrl+C (twice):Leave Claude Code's session completely. Use when you want to quit and return to the normal shell
  • • Ctrl+D:Sends EOF (End of File), equivalent to exiting the session. Works when the prompt is empty
Visual examples

⌨️Usage Scenarios

# Scenario 1: Claude is generating a very long response
> Explain the entire architecture of the Linux kernel...
# Claude starts generating 5000 words...
# Press Escape → Claude stops generating
> Summarize in just 5 lines

# Scenario 2: Claude executing a long command
Claude wants to run: find / -name "*.log" -mtime -30
# You approved but it's taking too long...
# Press Ctrl+C → Command canceled

# Scenario 3: Want to leave the session
> (empty prompt)
# Press Ctrl+C twice or Ctrl+D → Session closed
Practical Tip

💡Practical Tip

O Escape and your best friend. Use it liberally. If Claude starts generating something that isn't what you want, press Escape immediately. Don't wait for the response to finish to redo the prompt - this would waste tokens and time.

After canceling with Escape, you can refine the prompt. Claude maintains the context of the conversation, so just ask more specifically and he will correct the course.

🕐 Command History

Just as bash maintains a history of commands that you can navigate with the arrow keys, Claude Code also allows you tobrowse previous prompts. Reusing and adapting prompts that have already worked is one of the most efficient ways to work, avoiding retyping complex instructions.

Main Concept

🎯Main Concept

Claude Code stores the prompt history for the current session and allows you to browse them. This works similarly to bash history, but within the context of the Claude session.

  • • Up arrow:Returns to the previous prompt. Keep pressing to browse older session prompts
  • • Down arrow:Advances to the next (most recent) prompt. Use after navigating backward
  • • Reuse with editing:Navigate to a previous prompt, edit it with the editing shortcuts (Ctrl+A, Ctrl+E, Alt+B, etc.), and press Enter to send the modified version
  • • Persistent sessions:Useclaude --resumeto resume a previous session complete with full context and prompt history
Examples

⌨️Workflow with History

# Original prompt
> Refactor the processData function in src/utils.py to use async/await

# ...Claude responds and applies changes...

# Now you want to do the same for another function:
# Press Up Arrow (recalls previous prompt)
> Refactor the processData function in src/utils.py to use async/await
# Edit with Ctrl+W to change the function name:
> Refactor the validateInput function in src/utils.py to use async/await

# Summarize previous session
$ claude --resume
# Shows list of recent sessions to choose from
Practical Tip

💡Practical Tip

Develop the habit ofreuse prompts that worked. If you've found a prompt formula that generates excellent results (e.g. "refactor X to use Y while keeping the tests passing"), use the up arrow and adapt it rather than rewriting it from scratch.

For very complex prompts that you use frequently, consider saving them as aliases in the shell (module 1.7) or as snippets in a reference file. This is more efficient than relying on session history.

📝 Multi-line Input

Effective prompts often requiremultiple lines: detailed instructions, lists of requirements, code examples or structured templates. Claude Code supports multi-line input in a variety of ways, allowing you to compose complex prompts without sacrificing formatting.

Main Concept

🎯Main Concept

In Claude Code,Entersends the prompt. To insert a new line without submitting, you need to use alternative methods. There are several ways to compose multi-line prompts.

  • • Shift+Enter:Inserts a new line at the prompt without submitting. This is the main method for multi-line input in Claude Code
  • • Paste blocks (Ctrl+V / Cmd+V):When you paste multi-line text from the clipboard, line breaks are automatically preserved. Claude receives the full block
  • • Backslash continuation:In some contexts, you can use\at the end of the line to indicate continuation, similar to the shell
  • • Pipe with heredoc:For very large prompts, use pipe mode:claude -p << 'EOF' ... EOF
Examples

⌨️Multi-line Input Examples

# Using Shift+Enter for multiple lines in the interactive prompt
> Create a Python function that: [Shift+Enter]
1. Get a list of URLs [Shift+Enter]
2. Make async requests for each one [Shift+Enter]
3. Return a dict with URL: status_code [Enter to submit]

# Using heredoc for complex prompts via pipe
$ claude -p << 'EOF'
Refactor the src/auth.py file following these rules:
- Use dataclasses instead of dicts
- Add type hints to all functions
- Replace print() with logging
- Keep existing tests passing
EOF
Practical Tip

💡Practical Tip

For really complex prompts, considerwrite the prompt to a text fileand then send via pipe:cat meu_prompt.txt | claude -p. This allows you to use your favorite text editor (vim, VS Code) to compose the prompt calmly, with syntax highlighting and without fear of sending it by mistake.

Another technique: maintain a directory~/.prompts/with your most used prompts in .txt files, and run them withcat ~/.prompts/code-review.txt | claude -p.

🔧 Custom Shortcuts with keybindings.json

In addition to the standard shortcuts, Claude Code allowscustomize keybindingsthrough a configuration file. This means you can create shortcuts for frequent actions, map keys to your preference, and even create "chord bindings" for advanced workflows.

Main Concept

🎯Main Concept

The file~/.claude/keybindings.jsonallows you to define custom shortcuts for Claude Code. You can map any key combination to internal actions, slash commands or text macros.

  • • File location: ~/.claude/keybindings.json- create it if it doesn't exist. Claude Code loads automatically
  • • Format:JSON with array of objects, each with "key" (the key combination) and "command" (the action to be performed)
  • • Chord bindings:Sequences likeCtrl+K Ctrl+C(press Ctrl+K followed by Ctrl+C) for advanced actions
  • • Terminal integration:Claude Code's keybindings coexist with those of the terminal. Avoid conflicts by testing before defining new shortcuts
Configuration Example

⌨️Keybindings.json example

// ~/.claude/keybindings.json
[
{
"key": "ctrl+shift+r",
"command": "/review"
},
{
"key": "ctrl+shift+t",
"command": "/test"
},
{
"key": "ctrl+shift+c",
"command": "/commit"
},
{
"key": "ctrl+shift+h",
"command": "/help"
}
]
Practical Tip

💡Practical Tip

Start with a few keybindings and add as needed. The most useful are shortcuts for slash commands that you use frequently:/review, /commit, /clear.

Avoid conflicts with terminal shortcuts. Test each new keybinding to ensure you don't overwrite something important. UseCtrl+Shift+as a prefix to minimize conflicts, as this combination is rarely used by terminals.
